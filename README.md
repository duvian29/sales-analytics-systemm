# 📊 Sales Analytics System

Sistema web para gestionar productos, clientes, empleados y ventas, con un dashboard de análisis desarrollado en Power BI. La aplicación permite registrar y consultar información comercial y visualizar indicadores de ventas a partir de los datos almacenados en MySQL.

## 🚀 Tecnologías utilizadas

- React
- Vite
- Bootstrap
- Flask
- Python
- MySQL
- Power BI

## 📂 Estructura del proyecto

- frontend/ → Aplicación web desarrollada con React
- backend/ → API REST desarrollada con Flask
- database/ → Scripts y estructura de la base de datos MySQL
- docs/ → Documentación del proyecto

## ✨ Funcionalidades

- Gestión de Clientes
- Gestión de Empleados
- Gestión de Productos
- Registro de Ventas
- Consulta de ventas realizadas
- Cálculo automático del total de las ventas
- Control de inventario
- Dashboard de ventas en Power BI
- Visualización de indicadores comerciales
- Análisis de ventas por fecha
- Análisis de productos más vendidos
- Análisis de ventas por cliente
- Análisis de ventas por categoría

## 📊 Dashboard

El proyecto cuenta con un dashboard desarrollado en Power BI conectado a la base de datos MySQL.

Incluye indicadores como:

- Ventas Totales
- Número de Ventas
- Productos Vendidos
- Stock Disponible
- Ventas por Fecha
- Productos Más Vendidos
- Ventas por Cliente
- Ventas por Categoría

## 🗄️ Base de datos

La aplicación utiliza MySQL workbench como sistema gestor de base de datos.

Entre las principales tablas se encuentran:

- Clientes
- Empleados
- Productos
- Categorías
- Ventas
- Detalle de Ventas
- Inventario
