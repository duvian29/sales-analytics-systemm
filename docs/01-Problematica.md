# Sales Analytics System (SAS)

## 1. Descripción de la empresa

TechStore es una empresa dedicada a la venta de equipos tecnologicos y accesorios como computadores, monitores, teclados, mouse, impresoras y otros dispositivos electronicos. la empresa cuenta con vendedores, clientes y un inventario de productos que actualmente se administra de forma manual.

## 2. Situación actual

cada area de la empresa utiliza hojas de calculo independientes para registar la información de clientes, productos y ventas. esto provoca inconsistencias, duplicaciónes, y dificultades para obtener información confiable.

## 3. Problemas identificados

 Duplicidad de clientes
 Duplicidad de productos
 Errores en el registro de ventas
 Perdida de información 
 Dificultad para generar reportes
 Ausencia de indicadores en tiempo real
 Procesos manuales que consumen tiempo

## 4. Objetivo general

Desarrollar una aplicación web que permita administrar clientes, productos, empleados y ventas mediante una base de datos centralizada, ofreciendo información confiable para la toma de decisiones y generando indicadores mediante power BI 

## 5. Objetivos específicos

Registrar clientes
Registrar productos
Registar empleados
Registrar ventas
Consultar información
Automatizar reportes
Integrar la información con power BI

## 6. Beneficios esperados

Centralización de la información
Reducción de errores
Mejor control de ventas
Mejor administración de inventarios
Reporte rapidos
Información útil para la toma de decisiones

## 7. Alcance del proyecto

El sistema permitirá administrar la información principal del negocio mediante una aplicación web conectada a una base de datos MYSQL y ofrecerá un dashboard desarrollado en power BI para visualizar indicadores de ventas y mostar el desempeño comercial
