# Modelo entidad relación

## Entidades principales

Cliente
Empleado
Usuario
Producto
Categoria
Venta
Detalle de venta
Inventario

## Relaciones

Cliente puede tener muchas ventas
Empleado puede registrar muchas ventas
Una venta puede tener multiples productos
Un producto puede pertenecer a una categoria
El inventario controla la cantidad disponible de cada producto
