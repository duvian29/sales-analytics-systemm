# Diccionario de datos

## Tabla : roles

|  campo     |  tipo   | descripción |
|------------|---------|-------------|
| id_rol     |   int   | identificador del rol |
| nombre_rol | varchar | nombre del rol |
|descripción | varchar | descripción del rol |


## Tabla : usuarios

|   campo   |    tipo    |   descripción |
|-----------| -----------|---------------|
|id_usuario |    int     | identificador del usuario |
|nom_usua   |  varchar   | usuario de acceso |
| password  |  varchar   | contraseña        |
|id_rol     |    int     | rol asignado      |
