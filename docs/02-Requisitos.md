# Requisitos del Sistema

## 1. Requisitos Funcionales

## RF-01 Gestión de Clientes

El sistema permitirá crear, consultar, actualizar y eliminar clientes.

## RF-02 Gestión de Empleados

El sistema permitirá administrar la información de los empleados registrados.

## RF-03 Gestión de Productos

El sistema permitirá registrar productos, consultar su información, actualizar datos y gestionar su disponibilidad.

## RF-04 Gestión de Ventas

El sistema permitirá registrar ventas asociando clientes, empleados y productos.

## RF-05 Gestión de Inventario

El sistema permitirá controlar entradas, salidas y cantidades disponibles de productos.

## RF-06 Gestión de Reportes

El sistema permitirá consultar información mediante reportes de ventas, clientes, productos y empleados.

## RF-07 Dashboard Power BI

El sistema permitirá generar información para visualizar indicadores comerciales mediante Power BI.

## RF-08 Autenticación de Usuarios

El sistema permitirá el inicio de sesión mediante usuario y contraseña.

## RF-09 Control de Roles

El sistema permitirá manejar permisos según el tipo de usuario.

---

# 2. Requisitos No Funcionales

## RNF-01 Usabilidad

La aplicación deberá contar con una interfaz sencilla y fácil de comprender.

## RNF-02 Seguridad

El acceso al sistema estará restringido a usuarios registrados.

## RNF-03 Control de permisos

Cada usuario tendrá acceso según su rol dentro de la empresa.

## RNF-04 Rendimiento

La aplicación deberá responder de manera eficiente a las consultas principales.

## RNF-05 Mantenibilidad

El código deberá estar organizado para permitir futuras mejoras.

## RNF-06 Integración

La información deberá poder ser utilizada por Power BI para análisis y visualización.
